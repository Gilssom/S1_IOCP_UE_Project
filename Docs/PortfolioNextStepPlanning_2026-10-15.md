## 선택 콘텐츠: Dusk 처치 퀘스트 1종 — 미승인/미구현

- 제안 이름: 주변 위협 정리.
- 캐릭터별 1회 수락 → 수락 이후 Dusk 3마리 처치 → 보상 받기 → 회복 포션 3개.
- 처치 기여는 서버 확정 마지막 타격자 기준 제안. 기존 몬스터 드랍 기준과 일치하며
  파티/공동 기여도 규칙을 새로 만들지 않는다. 수락 전 처치는 소급하지 않는다.
- 서버가 고유 몬스터 생명/사망 이벤트를 기준으로 중복 집계를 막고 진행도를 저장한다.
  같은 스폰 위치에서 재생성된 새 몬스터의 처치는 새 실적으로 인정한다.
- 수락/진행/목표 달성/보상 완료 상태와 진행도는 서버·DB 소유다.
  클라이언트는 확정 상태를 표시하며 AnimNotify나 클라이언트 사망 화면으로 집계하지 않는다.
- 목표 달성 후 UI의 보상 받기를 누른다. 포션 3개를 전부 수용할 여유가 없으면
  지급·완료 처리를 하지 않고 목표 달성 상태를 유지한다. 공간 확보 후 다시 요청 가능.
- 보상 지급과 수령 완료 상태는 원자 처리하고 중복 클릭·응답 유실·재접속에도
  이중 지급하지 않는다. 기존 스택 상한 99와 실제 20칸 저장공간을 사용한다.
- 최소 UI는 단일 퀘스트 패널의 수락/진행 n/3/보상 받기/수령 완료 표시다.
  전용 NPC, 대화 연출, 새 맵·몬스터·아이템·음성은 추가하지 않는다.
  기존 S1 UMG 및 회복 포션 아이콘 재사용. 키 배정·최종 배치는 UI 조사 후 제안한다.

사용자 결정 항목: 퀘스트 추가 여부, 3마리/포션 3개 수치, 마지막 타격자 기준,
캐릭터당 1회 정책. 위 내용은 제안이며 승인으로 간주하지 않는다.
새 프로토콜과 DB 저장 구조는 구현 담당이 기존 소스 조사 후 구체적으로 제시한다.
정확한 패킷 번호·테이블·마이그레이션 범위는 아직 확정하지 않는다.

   중복 사망 집계 방지, 새 생명 인정, 두 계정 독립 진행 검증.

   공간 확보 후 정상 지급, 중복 요청/재접속 후 이중 지급 방지 검증.
